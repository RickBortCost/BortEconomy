                                    🔔 Avviso di prezzo

                                    Si apre GitHub con la richiesta compilata: conferma con "Submit new issue". La condizione viene controllata a ogni aggiornamento dei dati (ogni 30 minuti); quando si verifica ricevi una notifica e l'avviso si disattiva.

                                    Privacy e sicurezza

                                    Cassaforte cifrata

                                    Cifratura AES-256-GCM con chiave derivata dalla password (PBKDF2-SHA-256, 600.000 iterazioni). La password non lascia mai il dispositivo e non è recuperabile.

                                    Dati inviati agli assistenti AI

                                    Con ogni domanda l'assistente riceve notizie e quotazioni pubbliche del sito; i tuoi dati personali solo se li includi qui o usi i pulsanti di analisi del portafoglio. Le conversazioni non vengono salvate dal sito.

                                    I tuoi dati

                                    Più persone sullo stesso dispositivo? Crea un profilo per ciascuno, ognuno con la propria password.

                                    Come sono trattati i dati

                                    • Sul tuo dispositivo: chiavi API, portafoglio, composizione, preferiti e impostazioni restano nel browser (cifrati se attivi la cassaforte). Nessun account, nessun cookie, nessuna statistica di utilizzo.
                                    • Assistenti AI: le domande partono dal browser direttamente verso Anthropic, OpenAI o Google con la tua chiave.
                                    • Hosting: il sito è servito da GitHub Pages, che registra gli indirizzi IP per sicurezza. Caratteri e librerie sono ospitati sul sito stesso: nessuna richiesta a Google Fonts o ad altri CDN.
                                    • Richieste su GitHub (aggiunta di titoli, avvisi di prezzo): diventano issue del repository e, se il repository è pubblico, sono visibili a chiunque, come l'elenco degli avvisi.
                                    • Protezioni del sito: Content Security Policy che consente solo i file del sito e le API degli assistenti, nessun invio del referrer ai siti esterni, protezione dal clickjacking.
